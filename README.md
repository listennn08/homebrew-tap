# listennn08/homebrew-tap

Homebrew casks by listennn08.

## Claude Panes

A zellij-style desktop UI for Claude Code sessions (macOS, Apple silicon). It needs the `claude` CLI installed and logged in.

```sh
brew install --cask listennn08/tap/claude-panes
```

Upgrade with `brew upgrade --cask claude-panes`, remove with `brew uninstall --cask claude-panes`.
